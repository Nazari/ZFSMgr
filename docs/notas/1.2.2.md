## ZFSMgr 1.2.2 — command line

Still the command line client (`zfsmgr-cli`) and its daemon (`zfsmgr-agent`) only; the
graphical interface is planned for **2.0.0**.

Asset: `zfsmgr-cli-1.2.2.zip` (+ `.sha256`), one installer per system inside.

**Update every machine**: after installing the new client, run `install-daemon -a`. The
status area now tells you when a daemon is older than the client.

### New

- **Deleting files inside a dataset.** `destroy ds#content/<path>` deletes that file; a
  directory needs `-r`. It asks first, saying what and of which dataset. It never deletes the
  root of the dataset, anything under `.zfs` or of a snapshot, and it does not go into a child
  dataset mounted inside. The daemon checks all of it again, deletes symbolic links without
  following them, and never crosses into another filesystem. Not on Windows yet.
- **A more useful status area.** Instead of «schedules in green» it shows when the next
  scheduled snapshot is due and of which dataset; «no jobs running» when nothing runs (the jobs
  line appears when something does); and «outdated daemon: …» for daemons older than the
  client. The position is no longer repeated there: the prompt already shows it.

### Fixed

- **A misspelt `#section`** (`cd ds#xonten`) is refused at once, naming the valid ones
  (`#content`, `#properties`, `#permissions`, `#path`), instead of failing later at whatever
  ran inside it.
