## ZFSMgr 2.0.0rc3 (release candidate)

The third candidate of 2.0: [2.0.0rc2](https://github.com/Nazari/ZFSMgr/releases/tag/v2.0.0rc2)
with what came up using the interface on Windows.

Asset: **`zfsmgr-2.0.0rc3.jar`** (+ `.sha256`), the installer. With Java 21 or later, open it
(`java -jar zfsmgr-2.0.0rc3.jar`, or a double-click): it installs on this computer, then shows
your network and installs or updates ZFSMgr on the machines you mark. Without Java the .jar is
also a zip: unzip it and run the installer of your system in `zfsmgr-2.0.0rc3/`.

### Interface

- **A pool is also a dataset**: choosing a pool shows its own tab —state, disks, maintenance—
  and then the same tabs as any dataset for its root: summary and files, and in advanced mode
  properties, manage, send and organize.
- **The wait cursor** while the interface waits for what was asked —creating a pool, a copy,
  opening a branch—. The reads that refresh the status by themselves do not show it.
- The detail panel no longer asks the same thing several times while the first answer is on
  its way.

### Fixes

- Creating a pool with the options of another one (`create … --opts-as`, «Options like» in the
  interface) failed on Windows when the model pool was on Linux: it copied
  `compatibility=openzfs-2.4-linux`, a name OpenZFS on Windows does not have. Since OpenZFS 2.2
  the `-linux` and `-freebsd` files are the same as the generic one, and that is the name copied
  now.
