## ZFSMgr 1.2.1 — command line, fixes

A fixes release over 1.2.0. Still the command line client (`zfsmgr-cli`) and its daemon
(`zfsmgr-agent`) only; the graphical interface is planned for **2.0.0**.

Asset: `zfsmgr-cli-1.2.1.zip` (+ `.sha256`), one installer per system inside.

**Update every machine**: after installing the new client, run `install-daemon -a`. If a
schedule levels to the machine where you run the client, run `peers <machine> --push` again
on the machine that holds the schedule (see below).

### Fixed

- **A daemon could stop answering.** It served one connection at a time with no time limit:
  a connection that never spoke left it deaf to every client, and a slow request made all the
  others wait. Seen as «TLS handshake failed» or «the daemon did not answer». Each connection
  now has its own thread (up to 32 at once) and a 15 s limit on every read and write. This
  matters more with `peers <c> --listen 0.0.0.0`, which exposes the port to the network.
- **Levelling to the client's own machine failed.** `peers --push` handed over the client's
  Local connection as «local» at 127.0.0.1, which on the other machine means that machine
  itself: the levelling dialled its own daemon («the daemon certificate is not the expected
  one») or found no credentials. It now goes under the client machine's name, and
  `schedule --to zfsm://local/…` on a dataset of another machine stores that name too.
  The client's daemon must listen on the network for the other machine to reach it
  (`peers local --listen 0.0.0.0`); `peers --push` says so.
- **The shell asked for the sudo password right after starting** on a machine with no stored
  Local password: the schedule check in the background prompted at the terminal. Background
  checks never ask now; the status area says «not checked: local».
- **Messages half in Spanish, half in English** (e.g. the confirmation of `clear`): every text
  now comes out whole in the user's language.
- `rename -r` behaved differently through the daemon's RPC and its command line.

### Internal

The agent has one verb table and is split into units by area; the shell is split by command
family; the unit tests run as named cases. Formatting (`.clang-format`) and Spanish literals
outside the catalogs are checked by the CI. Leftovers of the retired web interface removed.
