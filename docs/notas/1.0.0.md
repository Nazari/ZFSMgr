## ZFSMgr 1.0.0 — command line only

**This release publishes the command line client (`zfsmgr-cli`) and its daemon
(`zfsmgr-agent`) only.** The graphical interface is **not included and has not been
tested** against this version; it is not expected before **2.0.0**.

Asset: `zfsmgr-cli-1.0.0.zip` (+ `.sha256`). One installer per system inside:
`instalar-linux.sh`, `instalar-macos.sh`, `instalar-freebsd.sh` (experimental) and
`instalar-windows.cmd`. Each checks the package, needs OpenZFS 2.3 or later if the machine
has OpenZFS at all, and can install the local daemon (`--con-daemon`).

### Highlights since 0.99.3

- **Wildcards and lists in `zfsm://` URLs** —`*`, `?`, `[..]`, `{a,b}`— with per-command
  rules: `ls` filters, reads gather one table, commands that modify show the exact list and
  confirm. `cp` and `rsync` follow the operating system: many sources, one target.
- **`cp`**: copy files and directories from anywhere to anywhere, including a single file
  between machines.
- **`install-daemon -a`**: brings the daemon —and `zfsmgr-cli`, where present— up to date on
  every known connection, leaving alone what is current; `--check` shows the plan.
- **`send --resume` / `--discard-partial`**: a receive that was cut off is detected before
  sending, and you decide whether to continue it or start over.
- **`ls`** of pools shows deduplication ratio and the RAM used by the dedup table; a STATUS
  column answers for volumes too.
- Copies between machines keep owner, group, mode and times, and **warn** when files carry
  ACLs or extended attributes they cannot preserve (use `send` for those).
- An SSH key path that does not exist is rejected; if it disappears later, the connection is
  set aside with a clear warning.
- OpenZFS terms (snapshot, hold, bookmark) stay in English in the Spanish texts; messages from
  the command layer are translated, and the daemon's are in English.

## ZFSMgr 1.0.0 — solo línea de órdenes

**Esta versión publica solo el cliente de línea de órdenes (`zfsmgr-cli`) y su daemon
(`zfsmgr-agent`).** La interfaz gráfica **no se incluye ni se ha probado** con esta versión;
no se espera hasta la **2.0.0**.

Se publica `zfsmgr-cli-1.0.0.zip` (+ `.sha256`), con un instalador por sistema. Lo más
destacado desde la 0.99.3: patrones en las URL `zfsm://` (también en `cp` y `rsync`, con las
reglas del sistema operativo), `cp` entre máquinas, `install-daemon -a` para poner al día
daemon y CLI en todas las conexiones, `send --resume` / `--discard-partial` para una recepción
cortada, deduplicación y su RAM en `ls`, aviso de ACL y xattr que no viajan entre máquinas, y
claves SSH que no existen rechazadas o apartadas.
