## ZFSMgr 2.0.0rc2 (release candidate)

The second candidate of 2.0: the same as [2.0.0rc1](https://github.com/Nazari/ZFSMgr/releases/tag/v2.0.0rc1)
—the graphical interface in Java, and the installer that sets up your network— with one fix
in the command line client.

Asset: **`zfsmgr-2.0.0rc2.jar`** (+ `.sha256`), the installer. With Java 21 or later, open it
(`java -jar zfsmgr-2.0.0rc2.jar`, or a double-click): it installs on this computer, then shows
your network and installs or updates ZFSMgr on the machines you mark. Without Java the .jar is
also a zip: unzip it and run the installer of your system in `zfsmgr-2.0.0rc2/`.

### Fixes

- `ls /` and `ls /<machine>` in the interactive shell are always a table. On a terminal too
  narrow for every column they printed one card per machine or pool; now the secondary columns
  are hidden first —connections: type, user, port, sudo, TLS; pools: dedup, DDT RAM, imported,
  type, compression, mounted— and a line below the table says which. `--format json` and
  `--format tsv` still carry every column.
