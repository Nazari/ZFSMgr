ZFSMgr @VERSION@  (@PAQUETE@)
==============================

Ejecute el guion de SU sistema desde este directorio:

  Linux (x86_64)                 sh install-linux.sh
  macOS (Apple Silicon e Intel)  sh install-macos.sh
  Windows (x64)                  install-windows.cmd   (doble clic, o desde una consola)
  FreeBSD (amd64)                sh install-freebsd.sh      EXPERIMENTAL: probado solo en 15.1

Cada guion detecta la arquitectura, comprueba la integridad del paquete antes de copiar
nada y, al terminar, comprueba que lo instalado arranca. Todos admiten:

  --dry-run       dice lo que haría, sin tocar nada       (Windows: -DryRun)
  --uninstall     quita lo instalado                      (Windows: -Uninstall)
  --cli-only      sin la interfaz gráfica                 (Windows: -CliOnly)
  --help          el resto de opciones                    (Windows: -Help)

Los mensajes salen en el idioma del sistema: en castellano si está en castellano, y si
no, en inglés.

OpenZFS: si la máquina lo tiene, debe ser @ZFSMIN@ o posterior. Si no lo tiene, ZFSMgr se
instala igual, como cliente para manejar otras máquinas. Con un OpenZFS válido, los
guiones ofrecen instalar también el daemon local (--with-daemon / --no-daemon;
Windows: -WithDaemon / -NoDaemon).

Linux: la interfaz se ha construido sobre glibc 2.43 y necesita esa versión o posterior.
macOS: si instala el daemon, conceda «Acceso total al disco» a
       /usr/local/libexec/zfsmgr-agent (Configuración del Sistema → Privacidad y Seguridad).

La configuración del usuario (~/.config/ZFSMgr, %APPDATA%\ZFSMgr) nunca se toca.

Versión 1.x: SOLO se publica y se prueba el CLI (zfsmgr-cli) y su daemon. La interfaz
gráfica NO está probada en esta versión y no se espera hasta la 2.0.0.


ZFSMgr @VERSION@  (@PAQUETE@) — English
-------------------------------------

Run the script for YOUR system from this directory:

  Linux (x86_64)                 sh install-linux.sh
  macOS (Apple Silicon & Intel)  sh install-macos.sh
  Windows (x64)                  install-windows.cmd   (double-click, or from a console)
  FreeBSD (amd64)                sh install-freebsd.sh      EXPERIMENTAL: tested on 15.1 only

Each script detects the architecture, checks the package's integrity before copying
anything and, at the end, checks that what it installed actually starts. All accept
--dry-run, --uninstall, --cli-only (no GUI) and --help (on Windows: -DryRun, -Uninstall,
-CliOnly, -Help). Messages come in the system's language: Spanish if it is Spanish,
English otherwise.

OpenZFS: if present, it must be @ZFSMIN@ or later. Without it ZFSMgr still installs, as a
client for managing other machines. With a valid OpenZFS, the scripts offer to install
the local daemon too (--with-daemon / --no-daemon; Windows: -WithDaemon / -NoDaemon).

Linux: the GUI is built on glibc 2.43 and needs that version or later.
macOS: if you install the daemon, grant «Full Disk Access» to
       /usr/local/libexec/zfsmgr-agent (System Settings → Privacy & Security).

Your configuration (~/.config/ZFSMgr, %APPDATA%\ZFSMgr) is never touched.

Version 1.x: ONLY the CLI (zfsmgr-cli) and its daemon are published and tested. The
graphical interface is NOT tested in this version and is not expected before 2.0.0.
