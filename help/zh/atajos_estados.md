# 导航与状态

- 在操作和刷新期间，光标会变为忙碌状态。
- 统一树现在是主要导航界面。
- 当前树选择不等同于逻辑上的 `Source` 和 `Target`。
- `Source` 和 `Target` 通过数据集上下文菜单显式设置。
- 顶部区域的 `源：` 一行反映已标记的内容。目标无需标记：就是你为发起该操作而打开菜单的那个节点。
- 如果连接断开：
  - 连接根节点仍然可见
  - 不显示子节点
- `Clone` 仅在以下条件满足时可用：
  - source 是 snapshot
  - target 是 dataset
  - 同一连接
  - 同一 pool
- 快照从 `@` 节点选择（不再有 `Select snapshot` 菜单）。
- 如果源或目标使用 OpenZFS `< 2.3.3`，`Copy`、`Level` 和 `Sync` 会被阻止。
- 只有存在真正的属性或权限草稿时，`应用更改` 才可用。这两者确实是成批编辑并用按钮应用的；
  操作则不是：按下即执行。
- 常规导航走缓存；刷新仅在显式操作或必须刷新的动作后触发。
