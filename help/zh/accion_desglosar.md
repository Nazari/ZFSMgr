# 操作：拆分

目标：把数据集中的目录转换为子数据集。

条件：

- **在 Windows 连接中不可用。** 那里的数据集挂载在存储池的驱动器号下，无法拥有自己的挂载点，
  因此新数据集不会位于该目录所在的位置：其文件会出现在驱动器根目录。该操作会显示为禁用并
  给出原因。参见`Windows 连接`。
- 在池树中选择数据集。
- 数据集必须处于**已挂载**状态：否则不会列出任何候选目录。
- 在 Unix 连接上需要安装 `zfsmgr-agent` 代理：没有 shell 备用方案。

## 选择要转换的目录及其名称

选择窗口有两列：目录，以及**它将变成的数据集**（可编辑）。

**上层目录不必一并转换。** `zfs create` 只要求*父数据集按名称*存在，与挂载点路径无关。因此可以在 `a` 和 `b` 保持为普通目录的情况下转换 `a/b/c`。

建议的名称反映了这一选择：同时被转换的层级用 `/` 分隔，未被转换的用 `:` 分隔。

```
仅选择 a/b/c      ->  <dataset>/a:b:c
选择 a、b 和 c    ->  <dataset>/a/b/c
```

勾选和取消勾选时该列会重新计算，但您手动编辑过的行除外。ZFS 只接受 `a-z A-Z 0-9 _ . : -` 和空格；`:` 是少数合法且几乎不出现在目录名中的字符，因此用它表示「该层级不是数据集」。名称无效、重复或已被占用时会以红色显示原因，并禁用「确认」按钮。

已按规范名称对应子数据集的目录会被隐藏。仅为定位其他项而显示的节点会被禁用。作为数据集无效的名称（含 `@`、`#`、`,`、`..` 或控制字符）会标记为不可选择。

## 执行内容

- 显示命令并请求确认，随即执行，期间界面会被阻塞。
- 每个字节只移动**一次**：先把每个目录复制到使用临时扁平名称的数据集，并排除那些将各自单独转换的子目录；只有当**全部**复制都通过校验后，才删除原目录并把数据集重命名为最终名称。
- 如果某个目录**已经是**另一名称数据集的挂载点（即保留了子数据集的「组装」操作留下的状态），则不复制，仅重命名。
- 如果待转换目录内部有已挂载的子数据集，会在删除任何内容之前先卸载，并在结束时重新挂载。
- *进度*框每两秒输出一行，包含当前项目、已复制的大小和速度：

```
[BREAKDOWN] 8 / 13: Disks/Bootables/Tools — 已复制 643.2 MiB，速度 64.1 MiB/s
```

## 重要提示

- 中间空间取自**池本身**（数据最终所在之处），而非系统 `/tmp`。最后一步是重命名，而不是第二次复制。
- 删除源目录之前会**校验复制是否完整**（`rsync` 空跑统计待传文件，并带重试）。若多次尝试后仍有缺失，操作会中止且**不删除任何内容**。
- 删除原目录时**不跨越挂载点**：若发现有未事先卸载的挂载内容，会中止而不是删除其内容。
- 若最终重命名失败，数据完好保存在临时数据集中，消息会说明它们的名称以及各自应改成的名称。**请勿销毁它们。**
- 当系统的 `rsync` 支持时，复制会保留 **ACL 和扩展属性**（自动检测）。
