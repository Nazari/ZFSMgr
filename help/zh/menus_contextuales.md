# 右键菜单

ZFSMgr 在统一树上使用右键菜单。

## 在连接上

![连接的右键菜单](qrc:/help/img/auto/connection-context-menu.png)

- 过去挂在连接表上的菜单，现在挂在连接的根节点上。
- 连接上的当前顺序：
  - `连接`
  - `断开`
  - `刷新`
  - 分隔线
  - `新建连接`
  - `编辑`
  - `删除`
  - 分隔线
  - `新建池`
  - 分隔线
  - `安装辅助命令`
  - `重装/更新守护进程`
  - `修复临时挂载点`
  - `导出 trust-store 到该连接`
  - `在……上授权 SSH 密钥`（子菜单，列出其他已连接的 SSH 连接）
  - 分隔线
  - `分屏并作为根`（子菜单：`右`、`左`、`下`、`上`）；若菜单是在分屏面板的根节点上打开的，
    则显示 `关闭`

启用条件：

- `连接`：连接被标记为已断开，且没有正在进行的操作。
- `断开` 与 `刷新`：连接已连上，且没有正在进行的操作。
- `编辑` 与 `删除`：在 Local 连接以及重定向到 Local 的连接上不可用。
- `新建池`：连接已连上。
- `安装辅助命令`：仅当刷新时检测到包管理器，并且对缺失的命令存在受支持的安装方案时才可用。
  不适用于 Windows 连接，它们只通过原生代理工作。
- `重装/更新守护进程`：任何远程连接，包括 Windows。
- `修复临时挂载点`：任何非 Windows 连接，包括 Local（本地数据集同样可能停留在临时挂载点上）。
- `导出 trust-store 到该连接`：任何远程连接；不适用于 Local，它本来就使用本地的 trust-store。
- `在……上授权 SSH 密钥`：仅限非 Windows 的 SSH 连接，且只会列出其他已连接的 SSH 连接。

`修复临时挂载点` 会先做一次只读扫描，列出因同步被中断而挂载点被移动的数据集，并在恢复前请求
确认（恢复前会先卸载）。失败的项会保留标记，可以重试。

## 守护进程的自动更新

刷新结束时，**只有**当需要关注的原因是版本或 API 不一致时，ZFSMgr 才会自动、无对话框地重装
守护进程。

daemon-rpc 的 TLS 等待会把连接标记为需要关注，但**不会**触发自动重装：重装会重新生成 TLS
材料，从而让「失败 → 重装 → 失败」的循环延续下去。这种情况下请手动使用 `重装/更新守护进程`
或 `导出 trust-store 到该连接`。

## 在池的合并根节点上

![已导入池的右键菜单](qrc:/help/img/auto/pool-context-menu-imported.png)

- 第一个子菜单是 `池`。
- `池` 中包含池级操作：
  - `更新状态`
  - `导入`
  - `导入并重命名`
  - `导出`
  - `历史`
  - `管理`
- `管理` 执行立即生效的操作（`Sync`、`Scrub`、`Upgrade`、`Reguid`、`Trim`、`Initialize`、
  `Clear`、`Destroy`），必要时会弹出参数对话框。
- 紧接 `池` 子菜单之后是 `分屏并作为根`，再往下是针对该双重节点的常规数据集操作。

## 在数据集与快照上

- 在 filesystem 数据集上（以及池的合并节点上）：
  - `管理属性显示`
  - `数据集`
  - `操作`
  - `标记为源`
  - `与源 …`（六个两端操作，见下）
  - `分屏并作为根`（子菜单：`右`、`左`、`下`、`上`）
- `数据集` 子菜单：
  - `创建`
  - `重命名`
  - `删除`
  - `挂载`：仅当数据集的 `canmount` 不为 `off`、`mountpoint` 有效，且**尚未**挂载时可用。
  - `卸载`：仅当**已**挂载时可用。不要求 `canmount`：一个数据集可能先被挂载，之后才被设为
    `canmount=off`，而那正是最需要卸载的时候。
  - `加密密钥`（`加载密钥`、`卸载密钥`、`更改密钥`）
  - `计划快照`
  - `权限`（`新建 Set`、`新建委派`）
- `操作` 子菜单（针对**数据**本身，而不是数据集的状态）：
  - `拆分`
  - `合并`
  - `从目录`
  - `到目录`
- 在快照上：
  - `管理属性显示`
  - `删除快照`
  - `回滚`
  - `新建 Hold`
  - `标记为源`
  - `与源 …`

## 六个源—目标操作

`复制`、`移动`、`克隆`、`同步文件`、`同步快照` 与 `Diff` 需要**两个**端点。它们不再有按钮：
改为从右键菜单发起，沿用复制/粘贴的思路。

1. 在起点的数据集或快照上点右键 → `标记为源`。
2. 在**任意另一个节点**上点右键：该节点即目标，`与源 <名称>` 子菜单提供这六项，并在每一项中
   写明源：

```
与源 datos@lunes ▸
   从 datos@lunes 复制到此处
   从 datos@lunes 移动到此处
   从 datos@lunes 克隆到此处
   从 datos@lunes 同步文件到此处
   与 datos@lunes 同步快照
   与 datos@lunes 比较
```

不需要标记目标：目标就是您点击的那个节点。顶部的 `源:` 一行会提示当前标记了什么，名称放不下
时，其工具提示会完整显示。

不适用的项会显示为**灰色，并在工具提示中给出原因**：源不是快照、池不一致、`Diff` 比较的是
同一数据集的两个时间点，或者两端的 OpenZFS 版本不兼容，无法传输。

- 在 hold 上：
  - `Release`

在池的合并节点上，`分屏并作为根` 紧跟在 `池` 子菜单之后，而不是排在最后。

## 在分屏面板的根节点上

- 若该节点是分屏面板的根，会出现：
  - `关闭`：关闭该面板并释放分隔条中的空间。

## 规则

- 破坏性操作会请求确认。
- 有若干操作以延迟方式工作，累积在 `待应用更改` 中。
- `标记为源` 会更新顶部的 `源:` 一行。目标不需要标记：它就是打开菜单时所在的节点。
- `@` 节点（快照分组）没有右键菜单。
- 在 `Dataset properties` 与 `Snapshot properties` 上，右键菜单只包含 `管理属性显示`。
- 连接根节点下非池根的子节点（`Properties`、`Info`）没有右键菜单。
- 在挂起（suspended）的池上，右键菜单中的大多数操作显示为禁用。
