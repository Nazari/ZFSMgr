# 操作：到目录

目标：将某个数据集的内容复制到所选连接主机上的目录。

条件：

- 在池树中选择数据集。
- 选择对象必须是数据集（不能是快照）。
- 在 Unix 连接上需要已安装 `zfsmgr-agent` 代理：没有基于 shell 的替代方案。

行为：

- 打开一个窗口以选择目标目录。
- 该操作会加入 `待应用更改`，只有在应用更改时才会执行。执行时会显示命令、请求确认，
  并在执行期间锁定界面。
- 将数据集重新挂载到一个临时挂载点，再用代理自带的复制功能搬运其内容（保留权限、
  硬链接、稀疏文件、扩展属性，以及随之而来的 POSIX ACL）。之所以要重新挂载，是为了
  让目标目录可以正是它原先挂载的那条路径。
- 复制成功结束后：
  - 可按复选框选择删除源数据集。
- 命令与结果（`[TODIR] ok`）会写入组合日志。

重要提示：

- **内容不会被合并**：先复制到临时区域，最后再整体交换，因此目标目录要么是原来的内容，
  要么是新的内容，绝不会停在中间状态。原有内容会被移到一旁作为备份，出错时予以恢复。
- 若目标目录本身已是 ZFS 挂载点，则会被**拒绝**。
- 在 Linux 与 macOS 上，复制会保留**扩展属性与 POSIX ACL**。FreeBSD 上不会：它使用另一
  套属性接口，尚未移植。
- **如果不删除数据集，它会保持挂载**在原来的挂载点上。请确认它与目标目录不会重叠。
- **删除任何东西之前确实会做校验**：复制结束后会统计目标中仍缺少的内容，并最多重试四次；
  若仍有遗漏，操作会以 `verify_failed` 中止，不会销毁数据集。
- 没有实时进度行：输出在结束时才出现。
