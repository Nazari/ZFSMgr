# 内联属性与列

ZFSMgr 直接在统一树中显示数据集与池的属性。

## 它们出现在哪里

- 数据集下：`Dataset properties`。
- 快照下：`Snapshot properties`。
- 非快照的数据集下，还可能出现 `权限`。
- 在池/根数据集合并而成的双重节点下，可能出现 `Pool Information`。
  - 其中可能出现 `设备`（池的 vdev/磁盘树）。
- 在 filesystem 类型的数据集中，快照挂在 `@` 节点之下。
- 在启用了 GSA 数据集的池中，可能出现 `计划的数据集`。
- 在连接下：`Properties`。
- 在连接下，`Info` 汇总了：
  - `General`
  - `Daemon`
  - `Commands`

## 显示方式

- 可见列数在树表头的右键菜单中调整。
- `属性列` 当前可选的范围为：
  - `4、6、8、10、12、14、16`
- 列宽在同一会话内切换连接或面板时会保留；不会跨越程序的两次启动。
- 树的垂直滚动是平滑的。

## 管理可见属性

在下列节点上点击右键：

- `Dataset properties`
- `Snapshot properties`
- `Pool Information`

可以打开 `管理属性显示`。

连接的 `Properties` 节点没有右键菜单：它的字段直接在行内编辑。

该对话框允许：

- 选择可见属性
- 拖放重新排序
- 创建分组
- 重命名分组
- 删除分组

分组按以下对象各自独立：

- 池
- 数据集
- 快照

## 内联编辑

- 可编辑的属性直接在树中修改。
- 支持继承的属性在适用时显示 `Inh.`。
- ZFS 权限也在行内编辑，但处于草稿模式。
- 用户属性（名称中含 `:` 的，例如 `org.fc16.gsa:*`）可编辑，同样显示继承控件。
- 以下属性不显示继承控件：只读属性、不适用于当前平台的属性，以及 `canmount`。
- 待应用更改列表已经取消，因此也不再有从中跳转到对象的功能。属性草稿会在表格中高亮显示。
