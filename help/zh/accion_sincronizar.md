# 操作：同步

> **如何发起.** 在源上点右键（`标记为源`），然后在**目标节点**上打开右键菜单：`以 … 为源` 子菜单中即有该操作。不再有按钮。若显示为灰色，原因见其提示。参见`右键菜单`。

目标：将源数据集内容同步到目标数据集。

条件：

- 源：已选择数据集。
- 目标：已选择数据集。
- 源和目标必须不同。
- 源和目标都必须使用 OpenZFS `2.3.3` 或更高版本。

行为：

- 按平台／连接方式使用 `rsync` 或 `tar`。
- 在 Windows 上，**同一台机器上的两个数据集之间**使用代理自带的复制（`--mutate-copy-tree`），无需 `rsync`。它是真正的同步：跳过已经相同的内容，支持 `--delete`，也能模拟执行，因此 `Check` 的表现与 Unix 上一致。
- 在 Windows 上**跨机器**时仍使用经由 SSH 的 `tar`（若两端都具备则配合 `zstd` 或 `gzip`），且**不带 `--delete`**：那种情况下它并非同步，而是复制。
- 该动作会先加入 `待执行更改`，只有在应用待执行更改时才真正执行。
- 在日志中显示进度（MB/GB）。
- 支持取消。
- 若任一端低于 `2.3.3`，该操作会被阻止。
