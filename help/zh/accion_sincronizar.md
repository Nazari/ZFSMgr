# 操作：同步

> **如何发起.** 在源上点右键（`标记为源`），然后在**目标节点**上打开右键菜单：`以 … 为源` 子菜单中即有该操作。不再有按钮。若显示为灰色，原因见其提示。参见`右键菜单`。

目标：将源数据集内容同步到目标数据集。

条件：

- 源：已选择数据集。
- 目标：已选择数据集。
- 源和目标必须不同。
- 源和目标都必须使用 OpenZFS `2.3.3` 或更高版本。

行为：

- 按平台/连接方式使用 `rsync` 或 `tar`。
- 该动作会先加入 `待执行更改`，只有在应用待执行更改时才真正执行。
- 在日志中显示进度（MB/GB）。
- 支持取消。
- 若任一端低于 `2.3.3`，该操作会被阻止。
